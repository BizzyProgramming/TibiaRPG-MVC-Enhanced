This is a turn based RPG game built with Java, inspired by the game Tibia. Itd allows account creation, character creation/selection
and combat simulation using multithreading and JDBC database connectivity. The application is structured using the
Model-View-Controller (MVC) design pattern to promote clean, modular code.

This is an ongoing project and will likely never be finished. I plan to continue expanding and refining it as I grow as a developer.
Planned enhancements include:

. Integratoin of JUnit testing for key systems
. A future frontend UI, possibly built with Thymeleaf or React

This project serves both as a passion project and a portfolio to demonstrate evolving proficienty in Java, OOP, JDBC, threading,
and scalable architecture.
